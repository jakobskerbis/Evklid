## Kinematika

| | |
|---|---|
| Enakomerno gibanje | $s = v t$ |
| Enakomerno pospešeno | $v = v_0 + a t$, $\; s = v_0 t + \dfrac{a t^2}{2}$, $\; v^2 = v_0^2 + 2 a s$, $\; s = \dfrac{(v_0 + v) t}{2}$ |
| Navpični met | $v = v_0 - g t$, $\; h = v_0 t - \dfrac{g t^2}{2}$, $\; h_{\max} = \dfrac{v_0^2}{2 g}$ |
| Vodoravni met | $x = v_0 t$, $\; y = \dfrac{g t^2}{2}$ |
| Poševni met | $v_x = v_0 \cos \alpha$, $\; v_y = v_0 \sin \alpha - g t$, domet $D = \dfrac{v_0^2 \sin 2\alpha}{g}$ |
| Kroženje | $v = \dfrac{2 \pi r}{t_0} = \omega r$, $\; \omega = \dfrac{2 \pi}{t_0} = 2 \pi \nu$, $\; a_r = \dfrac{v^2}{r} = \omega^2 r$ |
