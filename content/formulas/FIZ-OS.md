## Gibanje

| | |
|---|---|
| Hitrost | $v = \dfrac{s}{t}$ |
| Povprečna hitrost | $\bar{v} = \dfrac{s_{\text{celotna}}}{t_{\text{celoten}}}$ |
| Pospešek | $a = \dfrac{\Delta v}{\Delta t}$ |
| Enakomerno pospešeno (iz mirovanja) | $v = a t$, $\; s = \dfrac{a t^2}{2}$ |
| Prosti pad | $v = g t$, $\; h = \dfrac{g t^2}{2}$ |
| Pretvorba hitrosti | $1\,\dfrac{\text{m}}{\text{s}} = 3{,}6\,\dfrac{\text{km}}{\text{h}}$ |

:::simboli
v | hitrost | v = \dfrac{s}{t} | m/s | pri pospešenem gibanju in prostem padu: hitrost po času $t$
\bar{v} | povprečna hitrost | \bar{v} = \dfrac{s_{\text{celotna}}}{t_{\text{celoten}}} | m/s |
s | pot | | m | $s_{\text{celotna}}$: vsa prevožena pot
t | čas | | s | $t_{\text{celoten}}$: ves čas gibanja
a | pospešek | a = \dfrac{\Delta v}{\Delta t} | m/s^2 | za koliko m/s se hitrost spremeni v eni sekundi
\Delta v | sprememba hitrosti | | m/s | končna hitrost minus začetna hitrost
\Delta t | čas, v katerem se hitrost spremeni | | s |
g | težni pospešek | | m/s^2 | približno $10\,\mathrm{m/s^2}$
h | višina, s katere telo pade | h = \dfrac{g t^2}{2} | m |
:::

## Sile, gostota, tlak

| | |
|---|---|
| Gostota | $\rho = \dfrac{m}{V}$ |
| Teža | $F_g = m g$ |
| Newtonov zakon | $F = m a$ (rezultanta sil) |
| Prožna vzmet | $F = k x$ ($x$ raztezek) |
| Ravnovesje na vzvodu | $F_1 r_1 = F_2 r_2$ |
| Tlak | $p = \dfrac{F}{S}$ |
| Hidrostatični tlak | $p = \rho g h$ |
| Vzgon | $F_{vz} = \rho_{\text{tek}}\, g\, V_{\text{izp}}$ |
| Telo plava | $\rho_{\text{telesa}} < \rho_{\text{tekočine}}$ |

:::simboli
\rho | gostota | \rho = \dfrac{m}{V} | kg/m^3 | $\rho_{\text{tek}}$, $\rho_{\text{tekočine}}$: gostota tekočine; $\rho_{\text{telesa}}$: gostota telesa
m | masa | | kg |
V | prostornina | | m^3 |
V_{\text{izp}} | prostornina izpodrinjene tekočine | | m^3 | enaka prostornini dela telesa, ki je pod gladino
F_g | teža (sila teže) | F_g = m g | N |
g | težni pospešek | | m/s^2 | približno $10\,\mathrm{m/s^2}$
F | sila | | N | v $F = m a$ vsota vseh sil na telo; v $F = k x$ sila vzmeti; v $p = \dfrac{F}{S}$ sila, ki pritiska na ploskev
a | pospešek | | m/s^2 |
k | koeficient vzmeti | k = \dfrac{F}{x} | N/m | pove, kako trda je vzmet
x | raztezek vzmeti | | m | za koliko se vzmet podaljša
F_1, F_2 | sili na vzvodu | | N |
r_1, r_2 | ročici sil | | m | razdalja od osi vrtenja do prijemališča sile
p | tlak | p = \dfrac{F}{S} | Pa | v $p = \rho g h$ tlak v tekočini na globini $h$
S | ploščina ploskve | | m^2 |
h | globina pod gladino | | m |
F_{vz} | sila vzgona | F_{vz} = \rho_{\text{tek}}\, g\, V_{\text{izp}} | N | kaže navzgor

## Delo, energija, moč

| | |
|---|---|
| Delo | $A = F s$ |
| Kinetična energija | $W_k = \dfrac{m v^2}{2}$ |
| Potencialna energija | $W_p = m g h$ |
| Moč | $P = \dfrac{A}{t}$ |
| Izkoristek | $\eta = \dfrac{A_{\text{koristno}}}{A_{\text{vloženo}}} = \dfrac{P_{\text{izh}}}{P_{\text{vh}}}$ |
| Toplota | $Q = m c \Delta T$ |
| Temperatura | $T\,[\text{K}] = t\,[^\circ\text{C}] + 273$ |

:::simboli
A | delo | A = F s | J | $A_{\text{koristno}}$: koristno delo; $A_{\text{vloženo}}$: vloženo delo

s | pot v smeri sile | | m |
W_k | kinetična energija | W_k = \dfrac{m v^2}{2} | J |
W_p | potencialna energija | W_p = m g h | J |
m | masa | | kg |
v | hitrost | | m/s |

h | višina | | m |

## Elektrika in magnetizem

| | |
|---|---|
| Električni tok | $I = \dfrac{e}{t}$ ($e$ naboj) |
| Ohmov zakon | $U = R I$ |
| Zaporedna vezava | $I = I_1 = I_2$, $\; U = U_1 + U_2$, $\; R = R_1 + R_2$ |
| Vzporedna vezava | $U = U_1 = U_2$, $\; I = I_1 + I_2$, $\; \dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ |
| Električna moč | $P = U I$ |
| Električno delo | $A = U I t = P t$, $\; 1\,\text{kWh} = 3{,}6 \cdot 10^6\,\text{J}$ |

:::simboli
I | električni tok | I = \dfrac{e}{t} | A | $I_1$, $I_2$: tok skozi prvi in drugi upornik
e | električni naboj | | As | $1\,\mathrm{As} = 1\,\mathrm{C}$
t | čas | | s |
U | napetost | U = R I | V | $U_1$, $U_2$: napetost na prvem in drugem uporniku
R | električni upor | R = \dfrac{U}{I} | \Omega | $R_1$, $R_2$: upora posameznih upornikov; $R$: skupni (nadomestni) upor
P | električna moč | P = U I | W |
A | električno delo | A = U I t | J | merimo ga tudi v kWh
:::
