- nastavi: c = 0

## 0:26

Pri $c = 1$ je $D = 0$. Opazuj teme: leži na osi $x$, zato ima enačba eno dvojno rešitev $x = 1$.

- nastavi: c = 1

## 0:38

Pri $c = 2$ je $D = -4 < 0$. Parabola je v celoti nad osjo $x$, zato realnih rešitev ni; rešitvi sta konjugirano kompleksni.

- nastavi: c = 2

## 0:52

Pri $c = -6$ je $D = 28$, rešitvi sta $-1{,}65$ in $3{,}65$. Njuna vsota je $-\dfrac{b}{a} = 2$, produkt pa $\dfrac{c}{a} = -6$, kot pravita Vietovi formuli.

- nastavi: c = -6
